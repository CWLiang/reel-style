# ASS 特效技法

所有視覺特效 —— 標題卡、白閃、進度條、動態字幕 —— 都是 **ASS 字幕層**畫出來的，不是額外的影片濾鏡。

這樣做的三個好處：時間點精準到毫秒、整支影片只需渲染一次、要調整只改文字檔不用重新編碼。缺點是語法很醜，所以有這份筆記。

## 座標與顏色

`PlayResX/Y` 設成影片實際尺寸（1080x1920），這樣座標就等於像素。

**顏色是 BGR 不是 RGB**，而且 alpha 是反的（`00` = 不透明、`FF` = 全透明）：

```
#4A9EFF (亮藍) → &H00FF9E4A&
#FFC24D (琥珀) → &H004DC2FF&
```

## 畫矩形

ASS 的繪圖模式。這是白閃、暗轉、遮罩、進度條的共同基礎：

```
{\p1}m 0 0 l 1080 0 1080 1920 0 1920{\p0}
```

`\p1` 進入繪圖模式，`m` 移動，`l` 連線，`\p0` 離開。配 `\an7\pos(0,0)` 讓左上角對齊原點。

## 開場標題卡

三個圖層疊起來：

```
# 半透明黑幕（\1a&H72& 約 55% 不透明）
Dialogue: 1,0:00:00.00,0:00:02.60,Fx,,0,0,0,,{\an7\pos(0,0)\1c&H000000&\bord0\shad0\1a&H72&\fad(150,400)}{\p1}m 0 0 l 1080 0 1080 1920 0 1920{\p0}

# 大字，彈跳進場
Dialogue: 3,0:00:00.00,0:00:02.60,Title,,0,0,0,,{\an5\pos(540,760)\fad(120,300)\fscx78\fscy78\frz-3\t(0,130,\fscx104\fscy104\frz0)\t(130,220,\fscx100\fscy100)}我的會議室\N{\c&H00FF9E4A&}停在哪都能用

# 底線
Dialogue: 3,0:00:00.00,0:00:02.60,Fx,,0,0,0,,{\an5\pos(540,1000)\1c&H00FF9E4A&\bord0\shad0\1a&H20&\fad(300,300)}{\p1}m 0 0 l 320 0 320 6 0 6{\p0}
```

彈跳的關鍵是兩段 `\t`：78% → 104%（130ms，衝過頭）→ 100%（再 90ms，回彈）。加一點 `\frz-3` 轉回 0 度會更有彈性。

慢節奏的版本就單純 `\fad(520,600)` 加 97%→100% 的微放大，不要彈。

## 切點特效

**白閃**（快節奏）：切點前 1 幀開始，55% 白，140ms 淡出。

```
{\an7\pos(0,0)\1c&HFFFFFF&\bord0\shad0\1a&H55&\fad(0,140)}<全螢幕矩形>
```

**暗轉**（慢節奏）：切點前 130ms 開始，31% 黑，前後各留淡入淡出。

```
{\an7\pos(0,0)\1c&H000000&\bord0\shad0\1a&HB0&\fad(110,190)}<全螢幕矩形>
```

驗證有沒有生效：抽切點前後幾格算平均亮度。白閃應該看到 108 → 214 → 衰減，暗轉是 115 → 59 → 回升。看不出變化就是 alpha 給太保守了。

## 進度條

`\clip` 可以被 `\t` 動畫化，用這個做填充效果：

```
{\an7\pos(0,0)\1c&H00FF9E4A&\bord0\shad0\1a&H30&\clip(0,0,0,9)\t(0,38400,\clip(0,0,1080,9))}{\p1}m 0 0 l 1080 0 1080 9 0 9{\p0}
```

從 `\clip(0,0,0,9)`（寬 0）動畫到 `\clip(0,0,1080,9)`（全寬），時間等於影片總長（毫秒）。矩形本身是靜態的，動的是裁切框。

## 動態字幕

**彈跳**（快節奏）：

```
{\fad(0,90)\fscx88\fscy88\t(0,120,\fscx100\fscy100)}文字
```

**淡入**（慢節奏）：

```
{\fad(190,200)}文字
```

**關鍵字染色**：在字串裡插色碼，記得改完要改回白色，否則後面整句都會變色。

```
但我有陽明交大{\c&H004DC2FF&}校友證{\c&H00FFFFFF&} → {\c&H004DC2FF&}免費
```

## 中文換行

`WrapStyle: 2` 關掉自動換行，改用 `\N` 手動控制。中文字幕超過 14 字就該折行，優先在標點處斷：

```python
for i, ch in enumerate(txt):
    if ch in "，、。：？！":
        # 選最靠近中間的那個標點
```

自動換行在中文會斷在很醜的地方，一定要自己控制。

## 版面安全區

IG Reels 的畫面下方約 300-400px 會被貼文文案和右側按鈕蓋住。字幕的 `MarginV` 設 **420** 比較保險。

小字註記（口誤更正之類）放 `MarginV 610`，剛好在字幕正上方。

## 樣式建議值（1080 寬）

| 用途 | 字級 | 描邊 | 陰影 | 對齊 | MarginV |
|---|---|---|---|---|---|
| 字幕 | 72 | 6 | 2 | 2（底部置中） | 420 |
| 標題 | 122 | 7 | 4 | 5（正中） | 0（用 `\pos`） |
| 註記 | 46 | 4 | 1 | 2 | 610 |

字幕的描邊要夠粗（6px），因為手機畫面小、背景常常是亮的天空或牆壁。`ScaledBorderAndShadow: yes` 一定要開，不然換解析度時描邊粗細會跑掉。

## 圖層順序

`Dialogue:` 開頭的數字是 layer，大的蓋在上面：

```
1  開場黑幕
3  標題大字、底線
4  字幕、註記
5  切點白閃/暗轉      ← 蓋過字幕，切換時整個畫面一起閃才自然
6  進度條             ← 永遠在最上層
```
