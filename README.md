# reel-style

給 Claude 兩支影片：一支你**喜歡版面**的參考影片，一支你**自己拍**的原檔。
Claude 把參考影片的版面拆成數字，套到你的素材上，輸出 1080×1920 直式短影音。

它學的是**版面**（比例、色票、字卡型別、動態節奏），不是內容。

---

## 安裝

在 Claude Code 裡貼這兩行：

```
/plugin marketplace add CWLiang/reel-style
/plugin install reel-style
```

然後把兩支影片丟進去，說「照 A 的風格剪 B」。

第一次跑會先做環境檢查，缺什麼 Claude 會直接幫你裝，你按允許就好。

---

## 需要什麼

| | 說明 |
|---|---|
| **ffmpeg（含 libass）** | 唯一的硬需求。沒有 libass 就完全畫不出字卡。<br>macOS：`brew install ffmpeg-full`（**不是** `brew install ffmpeg`，那個精簡版沒有 libass） |
| **python3** | 有直譯器就夠，**不需要任何套件**。整條管線只用標準庫。 |
| **中文字型** | macOS 內建蘋方、Windows 內建微軟正黑體，通常不用裝 |
| 語音辨識 | 選配。原片已經有燒錄字幕的話用不到 |

環境檢查隨時可以自己跑：

```bash
bash skills/reel-style/scripts/doctor.sh
```

## 它做了哪四步

1. **量參考影片** — 抽影格拼成 contact sheet 讓 Claude 看出設計語彙，同時量出畫布主色、影片區塊上緣佔幾 %、左右內縮幾 %，寫成 `style.json`
2. **讀你的素材** — 偵測原片有沒有燒錄字幕（有的話會裁掉並重繪）、看構圖、抽逐字稿
3. **排版面** — 照論述結構分段，一段一張卡，每一列對準你講到那句話的秒數，寫成 `plan.json`
   **這一步會先給你看，你點頭才往下做**
4. **渲染** — 所有字卡都是 ASS 字幕層，ffmpeg 一次 pass 完成，接著自動驗收

改字卡只要重跑第 4 步，不用重新分析。

## 風格從哪裡來

**你的參考影片決定一切。** 這些全部是量出來或看出來的，不是預設值：

| | 怎麼得到 |
|---|---|
| 畫布色票、影片區塊上緣佔幾 %、左右內縮、圓角 | 腳本逐格量測 |
| 字卡型別、列項淡入時機、強調色、字級、動態節奏 | Claude 看 contact sheet 判斷 |
| 用哪一種渲染引擎 | **自動判定**——量得到影片卡邊界就用 `split`，量不到就是 `full` |

最後一項是實作細節，你不用選。`split` 是「影片縮成下方圓角卡、上方留白放字卡」，
`full` 是「影片滿版、字卡疊在畫面上」，腳本量完自己會知道是哪一種。

遇到這兩種引擎都不是的結構（例如影片嵌在中間帶狀區、角落浮動小窗），
在 `render.py` 加一個 mode 即可 —— 這是預期中的正常擴充，每加一種就多涵蓋一整族風格。

**同一份 `plan.json` 可以直接換風格重出**，因為風格與內容是分開的兩個檔案。

## 兩種用法

**A. 直接用現成風格**（最快，30 秒有成品）

```
用 split-canvas-cards 這個風格剪我的影片
```

現成風格有哪些、各自適合什麼構圖，看 [`skills/reel-style/styles/README.md`](skills/reel-style/styles/README.md)。
它們也都是這個工具自己量出來的，不是手工設計的。

**B. 給一支你喜歡的參考影片**（這才是重點）

```
照這支的風格剪我的影片
（附上參考影片和自己的原檔）
```

量完會自動把風格草稿存進 `~/.reel-style/styles/`，下次可以直接指名使用。
**用越久，你自己的風格庫越厚。**

## 已經幫你踩過的坑

這些都寫進流程裡了，你不會再遇到：

- **ASS 渲染不了 emoji。** Apple Color Emoji 是點陣字型，libass 讀不了，會消失或變豆腐方塊。改用向量畫的圓形編號、藥丸標籤與幾何符號（▸ ↓ → ★）。
- **iPhone 拍的是 HLG HDR。** 不 tone map 直接輸出會刷白——實測飽和度 11.3% → 22.8%，差一倍。
- **`-ss` 放在 `-i` 前面會讓 ASS 時間軸歸零。** 抽測試幀時最容易中招，看起來很像「特效沒生效」。
- **換段落換底色會暗閃。** 舊底色若比新底色的淡入早結束，中間會露出底層，亮度實測從 230 掉到 67。
- **白卡放在淺色底上會消失。** ASS 沒有模糊，要疊三層遞減透明度的假陰影。
- **iPhone 直錄音量常在 -22 LUFS**，在社群動態裡會明顯比別人小聲。預設會正規化到 -16。
- **iPhone 直式是 1920×1080 + rotation=90**，ffprobe 報的尺寸不能直接拿來算濾鏡鏈。

## 限制，講在前面

**不是一鍵完成。** 第一次做出來的版面通常要來回調兩三次。第 3 步刻意設了一道人工確認關卡——版面再漂亮，內容對應錯了整支就是廢的。

**版面自動，判斷不自動。** 「哪一句話該配哪張卡」是這條流程裡最值錢也最不能自動化的一步。

**只萃取版面參數，不要複製別人的內容。** 版面風格不受著作權保護，但文案、配樂、素材、口白結構會。這個工具是用來學版面的，不是用來照抄某個帳號的。
